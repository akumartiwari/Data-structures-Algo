# Data Structures & Algorithms — Java

A comprehensive Java collection of Data Structures and Algorithms problems, organized by topic and difficulty.

## Package Structure

- **`com.company`** — Core interview problems (LeetCode / FAANG-focused): arrays, trees, DP, graphs, strings, etc.
- **`Revision`** — Deduplicated / advanced / niche problems for deep revision
- **`AdvancedRevision`** — Advanced competitive programming topics (Segment Tree, Fenwick Tree, Bitmask DP, Digit DP, etc.)
- **`Graph`** — Graph algorithm implementations (BFS, DFS, DSU, Shortest Path, etc.)
- **`CFProblems`** — Codeforces problem solutions
- **`CF_Templates`** — Master competitive programming template (`B.java`) with reusable utilities
- **`SQL`** — SQL query practice

## Comment Format

Every method is annotated with a standardized comment block for quick reference:

```
/*
 * PROBLEM: <name> (LeetCode/GFG <number>)
 * <One-line description of what the problem asks>
 *
 * ALGORITHM: <technique, e.g. "Sliding Window", "Two Pointers + Sort", "DP (top-down memoization)">
 * TC: O(...) | SC: O(...)
 */
```
